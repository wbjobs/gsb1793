分块并发下载器

Fetch + Streams + IndexedDB + Web Worker · 断点续传 · 全局令牌桶限速 · 自动重试

总速度 — 分块大小 4MB · 断网或暂停后恢复只重传未完成分块 · 数据存于 IndexedDB

    暂无下载任务

    验收点验证方式

    • 下载中断可续：下载中点“暂停”或直接断网，再点“恢复”，进度不回退、不重复下载已完成分块。
    • 并发数可控：调整“并发分块数”立即生效，多个文件公平共享总并发。
    • 限速准确：设置 512 KB/s，总速度稳定收敛到设定值（允许初始 1 秒突发额度）。
    • 1GB 不崩：分块 Blob 落 IndexedDB，内存只保留在途分块；内置测试 npm test 用 1GB 虚拟文件验证。
    • 异常自动重试：测试服务器对 ?fail=N 前 N 次请求返回 500，观察“重试 N”事件后自动成功。
